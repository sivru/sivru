### 3.6 Scope vs budget — the actual blocker

The design's own effort estimate: **~32 working days, ~5–6.5 weeks**. Verified against the task sidecar's effort rollup (T1–T22 = ~32 days). Auto-ship global budgets:

| Budget | Limit | Estimated need (full v0.5.0) | Gap |
|--------|-------|-------------------------------|-----|
| Loop iterations | 30 | ≥ 60 (22 tasks × multiple attempts each) | 2× over |
| Wall clock | 360 min (6 hours) | ~32 working days | ~40× over |
| Commits | 100 | ~50 (one per task + fixes) | OK |
| Lines added | 25000 | ~8000–12000 (production code) + ~6000–10000 (tests + fixtures) | likely OK |

Wall clock is the binding constraint by an order of magnitude. Iteration count is also tight: T2–T5 alone (four language resolvers, each with a conformance test) likely consumes 8–12 iterations; T15–T17 (`--diff` + FP corpus of ≥10 fixtures) likely consumes another 6–8.

The v2.1 tuning notes in this skill explicitly call out the failure mode of "hitting the cap before finishing non-trivial features and shipping incomplete work to escape the cap." A single auto-ship run against the full v0.5.0 design will hit that mode.

### Decision
**Status: BLOCKED — scope mismatch between design and one auto-ship budget.**

The design is implementation-ready (iter-6 eng-review PASS, Accepted). The codebase is ready (chunker, state_id, cache, refreshStale, MCP convention all in place). The hard-stop check is clean (no auth, no schema, no secrets, no force-push).

The single blocker is **scope**: this is a 5–6.5 week feature being asked to land in one 6-hour auto-ship loop. Attempting it whole produces one of:
1. Mid-feature escalation with a half-built tree (most likely outcome).
2. Skipped tests and shortcuts to fit the budget (the v2.1 anti-pattern).
3. A 12000-line PR no human can review (violates code-review and QA-only constraints).

### Recommended fix
Slice along the design's "Suggested order" (lines 387–401). Each slice is one auto-ship run with its own gate, journal, and PR. Critical path is T1 → T2 → T6 → T7 → T8 (the spine, ~10.5 working days even in the best case).
